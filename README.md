# 법정동 PNU PDF 정리 도구

PDF를 확인하면서 법정동 코드와 지번으로 PNU를 만들고, 선택한 PDF를 규칙화된 파일명으로 출력 폴더에 복사하는 Windows 데스크톱 GUI 도구입니다.

## 주요 기능

- `법정동코드 전체자료.txt`를 로드하고 `존재여부`가 `존재`인 법정동만 사용합니다.
- 원본 폴더의 직속 PDF 목록, 전체 PDF 수, 남은 PDF 수를 보여주고, 선택한 PDF를 앱 안에서 바로 확인할 수 있습니다.
- 주소 일부와 지번을 입력한 뒤 검색하면 법정동 후보를 추천하고 첫 번째 후보를 자동 선택합니다.
- 선택된 법정동 코드와 지번으로 19자리 PNU를 생성합니다.
- PDF에서 주소 부분을 드래그하면 텍스트를 추출해 주소 입력과 검색을 자동으로 진행합니다.
- 연도, 문서 종류, PNU, 전체 주소를 조합해 최종 파일명을 미리 보여줍니다.
- 동일 파일명이 처음 충돌하면 기존 무번호 파일을 `__1`로 변경하고 새 복사본을 `__2`로 만들며, 이후에는 다음 번호를 붙여 덮어쓰기를 피합니다.
- 입력 폴더에 `.filemaker_work_state.json`을 저장해 완료 목록과 마지막 작업 상태를 복원합니다.
- PyInstaller standalone exe로 빌드해 Python 미설치 환경에서도 실행할 수 있습니다.

## 화면 구성

앱은 3개 영역으로 구성됩니다.

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 원본 PDF 폴더 선택, 직속 PDF 목록, 처리 완료 표시 |
| 가운데 | PDF 뷰어, 페이지 이동, 확대/축소, 폭 맞춤 |
| 오른쪽 | 출력 폴더 선택, 연도/문서 종류, 주소 검색, PNU/파일명 미리보기, 복사 |

## PDF 주소 영역 자동 입력

1. PDF에서 주소 부분을 왼쪽 마우스 버튼으로 드래그합니다. 영역의 텍스트로 주소 검색과 PNU 미리보기가 갱신됩니다.
2. 사각형 내부를 드래그하면 이동하고, 모서리를 드래그하면 크기를 조절합니다. 마우스를 놓으면 다시 읽습니다.
3. 다음 PDF를 선택하면 같은 페이지 번호와 상대 위치의 영역을 자동으로 읽습니다. 가로·세로 양식이 다르면 영역 위치를 조절하세요.

`영역 새로 지정`으로 사각형을 다시 그리거나, `영역 읽기`로 현재 영역을 다시 읽을 수 있습니다.
`영역 해제`는 자동 추출을 중단하고 입력한 주소는 유지합니다. `Esc`는 진행 중인 드래그를 취소합니다.
일반 페이지 이동은 자동 입력을 실행하지 않으며, 새 페이지에서 영역을 그리면 대상 페이지가 바뀝니다.

텍스트 레이어가 있으면 직접 추출하고, 선택 영역에 텍스트가 없으면 한글·영문 OCR을 자동 실행합니다.
`F8` 또는 ‘OCR 읽기’는 텍스트 유무와 관계없이 현재 영역을 OCR로 다시 읽습니다.
인식은 선택한 영역만 대상으로 로컬에서 수행하며 인터넷 연결이나 별도 Tesseract 설치가 필요하지 않습니다.
언어 모델은 `assets/ocr/tessdata`에 포함되어 있고 exe에도 함께 묶입니다.
원본 PDF는 변경하지 않습니다. 새 파일을 열 때는 이전 주소와 검색 결과를 초기화합니다.
영역은 앱을 실행하는 동안만 유지하며 재시작하면 초기화됩니다. 추출 결과를 확인·수정한 뒤 복사하세요.

OCR 처리 중에도 앱을 조작할 수 있습니다. `Esc`로 취소할 수 있고, 파일·영역·페이지를 바꾸거나
주소를 직접 수정하면 진행 중인 OCR을 취소해 이전 결과가 덮어쓰지 않도록 합니다.
처리 중에는 복사를 보류하며, 빈 결과나 오류는 기존 입력을 유지합니다. OCR 제한 시간은 60초입니다.
읽을 수 없는 글자는 직접 수정하고, 영역을 좁혀 `F8`로 다시 시도할 수 있습니다.

OCR 원문은 PDF 뷰어 아래 상태 안내에 마우스를 올리면 확인할 수 있습니다.
주소·지번 다음에 붙은 ‘번지 외N필’이나 인접 칸 문구는 주소 입력에서 제외될 수 있습니다.
OCR에는 오인식이 있으므로 특히 지번과 PNU를 확인한 뒤 복사하세요.

키보드로 영역을 다루려면 `Alt+5`를 누릅니다. 영역이 없으면 현재 페이지에 기본 사각형을 만듭니다.
방향키로 이동하고 `Shift+방향키`로 오른쪽·아래쪽 경계를 조절합니다.
기본 이동량은 2 PDF 포인트이며 `Ctrl`을 함께 누르면 0.5포인트씩 미세 조절합니다.
편집 영역이 화면 밖으로 나가면 뷰어가 자동 스크롤해 영역을 따라갑니다.
`Enter`로 추출·검색을 실행하고 이전 패널로 돌아가며, `Esc`로 편집 전 영역을 복원합니다.
다른 패널이나 파일·페이지로 이동하면 미확정 영역 편집은 취소됩니다.
`Ctrl+R`은 현재 영역을 다시 읽습니다. 키보드 편집 중이면 편집을 확정하고 읽습니다.

복사 성공 시 완료 창 대신 상태줄에 결과를 표시합니다.
기본으로 켜진 ‘복사 후 다음 미처리 파일로 이동’ 옵션은 다음 미처리 PDF를 열고 영역을 자동 추출합니다.
목록 끝에서는 앞쪽의 미처리 파일을 찾으며, 전부 처리했으면 현재 파일을 유지합니다.
옵션을 끄면 복사 후 현재 파일에 머뭅니다. 이 옵션은 앱 실행 중에만 유지됩니다.
오류·파일명 충돌은 기존 대화상자로 안내합니다.

버튼·입력창·목록에 마우스를 올리거나 `Tab`으로 포커스를 옮겨 잠시 기다리면 상세 툴팁이 나타납니다.
키를 누르거나 포커스를 옮기면 도움말이 사라집니다.

## 파일명 규칙

복사되는 파일명은 다음 형식을 사용합니다.

```text
{연도}_{문서종류}_{PNU코드}_{공백을_언더바로_대체한_전체주소}.{원본확장자}
```

예:

```text
2026_실태조사서_1168010100101230004_서울특별시_강남구_역삼동_123-4.pdf
```

Windows 파일명 금지 문자 `\ / : * ? " < > |`는 `_`로 치환합니다.

## PNU 생성 규칙

PNU는 다음 19자리 형식입니다.

```text
법정동코드10자리 + 산여부1자리 + 본번4자리 + 부번4자리
```

| 입력 | 산여부 | 본번 | 부번 |
| --- | --- | --- | --- |
| `123` | `1` | `0123` | `0000` |
| `123-4` | `1` | `0123` | `0004` |
| `산12-3` | `2` | `0012` | `0003` |

## 단축키

| 단축키 | 동작 |
| --- | --- |
| `Alt+1` | 원본 PDF 목록으로 이동 |
| `Alt+2` | 주소 입력칸으로 이동 |
| `Alt+3` | 추천 목록으로 이동 |
| `Alt+4` | 출력 폴더 파일 목록으로 이동 |
| `Alt+5` | 주소 영역 키보드 편집 |
| `Enter` | 주소 검색 또는 현재 목록 항목 선택 |
| `Ctrl+Enter` | 어느 패널에서든 현재 선택으로 파일 복사 (영역 편집은 먼저 확정) |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 이전/다음 PDF 파일 |
| `Ctrl+R` | 영역 다시 읽기 |
| `F8` | 현재 영역을 OCR로 다시 읽기 |
| OCR 중 `Esc` | OCR 취소, 현재 입력 유지 |
| `PageUp` / `PageDown` | PDF 이전/다음 페이지 |
| `Ctrl+-` / `Ctrl++` | PDF 축소/확대 |
| `Ctrl+0` | PDF 폭 맞춤 |
| 영역 편집 중 `방향키` / `Shift+방향키` | 영역 이동 / 크기 조절 (`Ctrl`과 함께 미세 조절) |
| 영역 편집 중 `Enter` / `Esc` | 추출·확정 / 변경 취소 |
| 뷰어에서 편집 중이 아닐 때 `방향키` | PDF 화면 이동 |
| 주소 입력 중 `Shift+방향키` | 텍스트 선택 |
| `F5` | 목록 새로고침 |

## 개발 실행

Python 3.13을 사용합니다. 프로젝트 루트에서 가상환경을 만들고 의존성을 설치합니다.

```powershell
& "$env:LOCALAPPDATA\Python\pythoncore-3.13-64\python.exe" -m venv --without-scm-ignore-files .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe app.py
```

실행에는 `PyMuPDF`, exe 빌드에는 `PyInstaller`가 필요합니다.
가상환경을 활성화하지 않아도 위처럼 프로젝트 Python을 직접 실행할 수 있습니다.
활성화하려면 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

## 테스트

기존 로직과 PDF 영역 좌표·추출 및 GUI 동작을 검사합니다. GUI 테스트는 Windows 데스크톱에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest
```

`test_ocr.py`는 모델 무결성, OCR 취소·오류·이전 결과 방지 및 실제 PDF의 주소·PNU 결과를 검사합니다.
로컬 샘플이 없으면 실제 파일 검사만 생략합니다. 결과는 `build/ocr-actual-results.json`에 저장합니다.
검증 대상은 와룡동 2-122 측량성과도와 우이동 106-1 토지대장입니다.
OCR 엔진과 언어 모델의 출처·라이선스는 [assets/ocr/README.md](assets/ocr/README.md)를 참고하세요.

GUI 없이 소스 또는 빌드된 exe의 OCR 워커를 검증할 수도 있습니다. 영역 좌표는 페이지 대비 0~1 비율입니다.

```powershell
.\.venv\Scripts\python.exe app.py --ocr-check '검사할.pdf' --region 0.1 0.1 0.5 0.2 --page 1 --output 'build/ocr-check.json'
```

## 수동 테스트 자료

전달할 테스트 PDF는 프로젝트의 `test_files/` 폴더 바로 아래에 넣습니다.
앱에서 원본 PDF 폴더로 `test_files/`를 선택하면 됩니다. 하위 폴더의 PDF는 읽지 않습니다.
복사 결과를 확인할 출력 폴더는 원본 폴더와 별도로 선택합니다.

`test_files/` 내부 자료는 `.gitignore`로 Git 추적에서 제외하며, 폴더 유지를 위한 `.gitkeep`만 추적합니다.
자동 테스트 코드인 `test_app.py`는 계속 추적합니다.

## 빌드

PyInstaller로 onefile/windowed exe를 생성합니다.

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean '법정동PNU파일복사도구.spec'
```

빌드 결과는 기본적으로 `dist/법정동PNU파일복사도구.exe`에 생성됩니다.
