# 법정동 PNU PDF 정리 도구 v0.7.3

PDF를 확인하면서 법정동 코드와 지번으로 PNU를 만들고, 선택한 PDF를 규칙화된 파일명으로 출력 폴더에 복사하는 Windows 데스크톱 GUI 도구입니다.

## 주요 기능

- `법정동코드 전체자료.txt`를 로드하고 `존재여부`가 `존재`인 법정동만 사용합니다.
- 원본 폴더의 직속 PDF 목록, 전체 PDF 수, 남은 PDF 수를 보여주고, 선택한 PDF를 앱 안에서 바로 확인할 수 있습니다.
- 주소 일부와 지번을 입력한 뒤 검색하면 법정동 후보를 추천하고 첫 번째 후보를 자동 선택합니다.
- 선택된 법정동 코드와 지번으로 19자리 PNU를 생성합니다.
- PDF에서 주소 부분을 드래그하면 텍스트를 추출해 주소 입력과 검색을 자동으로 진행합니다.
- 연도, 문서 종류, PNU, 전체 주소를 조합해 최종 파일명을 미리 보여줍니다.
- 동일 파일명이 처음 충돌하면 기존 무번호 파일을 `__1`로 변경하고 새 복사본을 `__2`로 만들며, 이후에는 다음 번호를 붙여 덮어쓰기를 피합니다.
- 입력 폴더에 `.filemaker_work_state.json`을 저장해 완료 목록과 마지막 작업 상태를 복원합니다.
- PyInstaller standalone exe로 빌드해 Python 미설치 환경에서도 실행할 수 있습니다.

원본 PDF 목록은 마우스 버튼을 놓을 때 파일을 엽니다. 누른 행과 놓은 행이 다르거나
그 사이에 목록이 새로고침되면 전환을 취소합니다. 이미 열린 파일을 다시 선택해도
주소 입력과 OCR 결과를 초기화하지 않습니다. 방향키로 파일을 이동하는 기능은 유지합니다.
새로고침 버튼과 `F5`는 현재 파일의 선택과 목록 스크롤 위치를 유지합니다.
현재 파일이 목록에서 사라졌으면 뷰어와 입력을 비워 오래된 PDF로 작업하지 않도록 합니다.
복사 완료 시에는 완료된 행의 표시와 남은 개수만 갱신합니다.
외부에서 추가·삭제한 파일은 새로고침 버튼 또는 `F5`로 목록에 반영합니다.

PDF를 열면 원본 폴더의 직속 PDF 중 내용이 같은 파일을 자동으로 검색합니다.
일치하는 파일이 있으면 목록 위에 개수와 **일치 파일 보기** 버튼이 나타납니다.
새로고침 위에는 현재 PDF의 SHA-256 해시가 표시되며, **같은 해시 파일 찾기**로 검색을 다시 실행할 수 있습니다.
검색은 같은 크기의 PDF만 해시하고, 변경되지 않은 파일의 해시는 메모리에서 재사용합니다.
복사가 필요 없는 원본은 **작업 불필요 · 완료**를 눌러 완료 표시할 수 있습니다.
현재 PDF를 화면에 유지하며, 완료 표시는 다시 열어도 유지됩니다.

## v0.7.1_ocr 측량성과도 여러 지번 복사

문서 종류가 **측량성과도**이면 PDF 뷰어 아래에 전용 도구가 나타납니다.
실태조사서는 기존 단일 주소·파일 복사 방식을 사용합니다.

1. 상단 **토지소재 영역**과 하단 면적표의 **지번 열 영역**을 확인합니다.
   위치가 다른 양식은 **이전/다음**으로 원하는 페이지를 연 뒤 해당 영역 버튼을 누르고 글씨를 드래그합니다.
   영역 버튼은 현재 페이지에서 지정하며, 지정 모드에서도 페이지를 이동할 수 있습니다.
   두 영역은 서로 다른 페이지에도 지정할 수 있으며 원본 폴더별로 저장됩니다.
2. **두 영역 읽기**, `Ctrl+R` 또는 `F8`로 읽습니다. 다음 PDF를 열면 같은 영역으로 자동 읽습니다.
   토지소재는 주소 한 줄 전체(번지·외 ○필 포함)를 지정하세요. 기존 PDF 텍스트를 사용하지 않고
   **한국어 PP-OCRv5**로 이미지를 읽습니다. 모델은 exe에 포함되며 오프라인 CPU로 실행합니다.
   최초 읽기는 모델 로딩으로 더 걸릴 수 있습니다. 면적표는 기존 Tesseract로 검정·회색 글씨를 남겨 OCR합니다.
   빨간 지번·기호를 제외하며 면적 칸 숫자가 섞이지 않도록 지번 열만 지정해야 합니다.
3. 오른쪽에서 **공통 법정동**을 확인·선택합니다. PNU에는 앱 법정동 자료의 코드를 사용합니다.
   원본 파일명에 들어 있는 코드와 다를 수 있습니다. 토지소재에 산 표기가 있으면 지번에 적용하며,
   목록에서 산 표기와 본번·부번을 직접 수정할 수 있습니다.
4. 지번 목록을 원문과 비교합니다. 행 선택 시 원문 위치를 표시합니다.
   첫 칸 클릭 또는 `Space`로 포함/제외하고, 입력칸의 **추가·수정·삭제**로 오인식을 보정합니다.
   PNU와 파일명은 각 행에 표시되며 가로 스크롤로 전체 파일명을 볼 수 있습니다.
5. **지번·공통주소를 확인했습니다**를 체크하고 복사 버튼, `Ctrl+Enter`, 마우스 뒤로/앞으로 버튼을 누릅니다.
   선택된 지번마다 원본 PDF 전체를 각각 다른 이름으로 복사합니다. 페이지를 분할하거나 원본을 수정하지 않습니다.

예시 지동 측량성과도는 검정 지번 `301-6`, `301-37`, `301-45`를 추출합니다.
앱 자료에서 선택한 법정동 `4111513900`을 기준으로 각 PNU를 새로 계산합니다.
상단의 ‘외13필’ 숫자를 복사 개수로 사용하지 않습니다.

색상 정보가 없는 흑백 스캔에서는 원래 빨강이었던 글씨를 자동 구분할 수 없습니다.
빨강 미검출·색상 확인 안내가 나오면 원문을 확인하고 불필요한 지번을 직접 제외하세요.
글씨가 흐리거나 겹친 경우 OCR 누락·오인식이 있을 수 있습니다. `Esc`로 읽기를 취소할 수 있습니다.

### 일괄 복사와 실패 재시도

- `1/3 복사 중…`처럼 항목 수를 표시합니다. 선택한 지번이 모두 성공해야 원본을 완료 처리하고 다음 파일로 이동합니다.
- 파일명 충돌은 일괄 확인한 뒤 기존 `__1`, `__2` 규칙을 적용합니다.
- 항목별 복사 예정 경로와 결과를 상태 파일에 기록합니다. 실패 후 다시 복사하면 이전 성공 파일의
  이름·위치·내용 해시를 검증하고 건너뛰며 나머지만 복사합니다.
- 복사를 시작한 미완료 목록은 수동 수정한 지번·포함 여부·선택 법정동과 함께 저장합니다.
  같은 원본·연도·출력 폴더로 다시 열면 복원하며 확인 체크는 다시 해야 합니다.
- 원본 또는 출력 파일의 내용이 바뀌면 이전 성공 기록만으로 건너뛰지 않습니다.
- 일반 복사도 고유 임시 파일에 먼저 쓰고 게시하며, 복사 실패 시 해당 임시 파일을 정리합니다.
  이전 버전이나 강제 종료로 이미 남은 임시 파일은 자동 삭제하지 않습니다.

기존 버전의 완료 표시는 유지합니다. 이전 측량성과도의 추가 지번을 복사하려면 해당 원본을 직접 선택하세요.

## v0.6.1부터 적용된 대량 작업 최적화

- 파일 경로와 목록 위치는 폴더를 읽거나 새로고침할 때 인덱스로 만듭니다.
  복사 후에는 목록 전체의 경로를 반복 확인하지 않고 완료된 행과 개수만 갱신합니다.
- 출력 목록도 새 복사본과 이름이 변경된 항목만 갱신합니다. 외부 변경은 `F5`로 반영하며,
  실제 복사 직전의 파일명 충돌 검사는 그대로 수행합니다.
- 다음 파일 선택까지 마친 뒤 완료 목록과 마지막 선택을 한 번 저장합니다.
  상태 파일은 임시 파일에 쓴 뒤 교체하므로 저장 실패 시 이전 상태를 보존합니다.
- 진행 막대는 목록 갱신과 상태 저장을 포함한 복사 후처리가 끝날 때까지 유지합니다.
- 성능 보고서에 복사 전 검사, 상태 저장, 완료 표시, 출력 갱신, 다음 파일 선택,
  후처리 및 복사 트랜잭션 시간을 추가했습니다.

1,300개 중 1,000개를 완료한 Mac 재현 실험에서 후처리 중앙값은 약 265ms에서 2.7ms로,
경로 확인은 14,312회에서 3회로 줄었습니다. 이 실험은 화면 그리기·파일 복사 I/O·PDF 렌더링을
제외한 비교이며, Windows의 전체 작업 시간 개선률을 뜻하지 않습니다.

## v0.6.0부터 적용된 성능 개선

- PDF 이미지는 별도 프로세스에서 렌더링하며, 창 크기를 연속으로 바꿀 때 중복 요청을 합칩니다.
- 현재 파일을 확인하는 동안 다음 미처리 PDF 1개의 화면과 주소 영역을 미리 준비합니다.
  텍스트가 없으면 기존 한글·영문 모델로 OCR하고, 해당 파일로 이동하면 준비된 결과를 사용합니다.
- 렌더링과 사전 인식은 서로 다른 프로세스에서 실행합니다. 사전 인식 워커는 재사용하며,
  예상하지 않은 파일을 열거나 `F8`을 누른 경우에는 기존 취소 가능한 OCR 작업을 실행합니다.
- 이미지 캐시는 최대 64MiB/8건, 영역 결과 캐시는 최대 1MiB/16건으로 제한합니다.
  이는 캐시 상한이며 앱 전체 메모리 사용량의 상한은 아닙니다.
- 파일 수정 시각·크기, 페이지, 확대율, 영역을 구분해 결과를 재사용합니다.
  이전 선택의 작업 결과는 현재 화면이나 직접 수정한 주소를 덮어쓰지 않습니다.
- 법정동 검색의 반복 전처리와 파일명 미리보기의 반복 폴더 탐색을 줄였습니다.
  실제 복사 직전에는 파일명 충돌을 새로 검사합니다.

큰 도면의 렌더링은 최대 약 1,600만 화소로 제한합니다. 명시적 확대가 이 상한에 걸리면
실제 표시 배율과 ‘큰 도면 해상도 상한’을 상태줄에 표시합니다.
렌더링은 30초, OCR 사전 준비는 60초 제한을 적용합니다.

실제 Windows PC에서 구간별 시간을 수집하려면 다음처럼 실행하고 평소 작업 후 앱을 닫습니다.
성능 JSON에는 파일명이나 주소 대신 구간별 시간과 표본 수만 저장합니다.

```powershell
& '.\법정동PNU파일복사도구_v0.7.3.exe' --performance-report '.\performance.json'
```

## 화면 구성

앱은 3개 영역으로 구성됩니다.

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 원본 PDF 폴더 선택, 직속 PDF 목록, 처리 완료 표시 |
| 가운데 | PDF 뷰어, 페이지 이동, 확대/축소, 폭 맞춤 |
| 오른쪽 | 출력 폴더 선택, 연도/문서 종류, 주소 검색, PNU/파일명 미리보기, 복사 |

## PDF 주소 영역 자동 입력

1. PDF에서 주소 부분을 왼쪽 마우스 버튼으로 드래그합니다. 영역의 텍스트로 주소 검색과 PNU 미리보기가 갱신됩니다.
2. 사각형 내부를 드래그하면 이동하고, 모서리를 드래그하면 크기를 조절합니다. 마우스를 놓으면 다시 읽습니다.
3. 다음 PDF를 선택하면 같은 페이지 번호와 상대 위치의 영역을 자동으로 읽습니다. 가로·세로 양식이 다르면 영역 위치를 조절하세요.

`영역 새로 지정`으로 사각형을 다시 그리거나, `영역 읽기`로 현재 영역을 다시 읽을 수 있습니다.
`영역 해제`는 자동 추출을 중단하고 입력한 주소는 유지합니다. `Esc`는 진행 중인 드래그를 취소합니다.
일반 페이지 이동은 자동 입력을 실행하지 않으며, 새 페이지에서 영역을 그리면 대상 페이지가 바뀝니다.

텍스트 레이어가 있으면 직접 추출하고, 선택 영역에 텍스트가 없으면 한글·영문 OCR을 자동 실행합니다.
`F8` 또는 ‘OCR 읽기’는 텍스트 유무와 관계없이 현재 영역을 OCR로 다시 읽습니다.
인식은 선택한 영역만 대상으로 로컬에서 수행하며 인터넷 연결이나 별도 Tesseract 설치가 필요하지 않습니다.
언어 모델은 `assets/ocr/tessdata`에 포함되어 있고 exe에도 함께 묶입니다.
원본 PDF는 변경하지 않습니다. 새 파일을 열 때는 이전 주소와 검색 결과를 초기화합니다.
영역은 앱을 실행하는 동안만 유지하며 재시작하면 초기화됩니다. 추출 결과를 확인·수정한 뒤 복사하세요.

OCR 처리 중에도 앱을 조작할 수 있습니다. `Esc`로 취소할 수 있고, 파일·영역·페이지를 바꾸거나
주소를 직접 수정하면 진행 중인 OCR을 취소해 이전 결과가 덮어쓰지 않도록 합니다.
처리 중에는 복사를 보류하며, 빈 결과나 오류는 기존 입력을 유지합니다. OCR 제한 시간은 60초입니다.
읽을 수 없는 글자는 직접 수정하고, 영역을 좁혀 `F8`로 다시 시도할 수 있습니다.

OCR 원문은 PDF 뷰어 아래 상태 안내에 마우스를 올리면 확인할 수 있습니다.
주소·지번 다음에 붙은 ‘번지 외N필’이나 인접 칸 문구는 주소 입력에서 제외될 수 있습니다.
OCR에는 오인식이 있으므로 특히 지번과 PNU를 확인한 뒤 복사하세요.

키보드로 영역을 다루려면 `Alt+5`를 누릅니다. 영역이 없으면 현재 페이지에 기본 사각형을 만듭니다.
방향키로 이동하고 `Shift+방향키`로 오른쪽·아래쪽 경계를 조절합니다.
기본 이동량은 2 PDF 포인트이며 `Ctrl`을 함께 누르면 0.5포인트씩 미세 조절합니다.
편집 영역이 화면 밖으로 나가면 뷰어가 자동 스크롤해 영역을 따라갑니다.
`Enter`로 추출·검색을 실행하고 이전 패널로 돌아가며, `Esc`로 편집 전 영역을 복원합니다.
다른 패널이나 파일·페이지로 이동하면 미확정 영역 편집은 취소됩니다.
`Ctrl+R`은 현재 영역을 다시 읽습니다. 키보드 편집 중이면 편집을 확정하고 읽습니다.

복사 성공 시 완료 창 대신 상태줄에 결과를 표시합니다.
복사 중에는 복사 버튼 아래에 움직이는 진행 막대와 ‘복사 중…’ 문구를 표시합니다.
진행 막대는 처리 중임을 알리는 표시이며, 복사율(%)을 나타내지는 않습니다.
파일 복사는 별도 스레드에서 실행합니다. 복사 중에는 입력과 단축키를 잠시 막아
중복 복사와 대상 변경을 방지하며, 완료 또는 실패 시 다시 사용할 수 있습니다.
복사 중 앱을 닫으면 파일 복사와 작업 상태 저장을 마친 뒤 종료합니다.
기본으로 켜진 ‘복사 후 다음 미처리 파일로 이동’ 옵션은 다음 미처리 PDF를 열고 영역을 자동 추출합니다.
목록 끝에서는 앞쪽의 미처리 파일을 찾으며, 전부 처리했으면 현재 파일을 유지합니다.
옵션을 끄면 복사 후 현재 파일에 머뭅니다. 이 옵션은 앱 실행 중에만 유지됩니다.
오류·파일명 충돌은 기존 대화상자로 안내합니다.

버튼·입력창·목록에 마우스를 올리거나 `Tab`으로 포커스를 옮겨 잠시 기다리면 상세 툴팁이 나타납니다.
키를 누르거나 포커스를 옮기면 도움말이 사라집니다.

## 파일명 규칙

복사되는 파일명은 다음 형식을 사용합니다.

```text
{연도}_{문서종류}_{PNU코드}_{공백을_언더바로_대체한_전체주소}.{원본확장자}
```

예:

```text
2026_실태조사서_1168010100101230004_서울특별시_강남구_역삼동_123-4.pdf
```

Windows 파일명 금지 문자 `\ / : * ? " < > |`는 `_`로 치환합니다.

## PNU 생성 규칙

PNU는 다음 19자리 형식입니다.

```text
법정동코드10자리 + 산여부1자리 + 본번4자리 + 부번4자리
```

| 입력 | 산여부 | 본번 | 부번 |
| --- | --- | --- | --- |
| `123` | `1` | `0123` | `0000` |
| `123-4` | `1` | `0123` | `0004` |
| `산12-3` | `2` | `0012` | `0003` |

## 단축키

| 단축키 | 동작 |
| --- | --- |
| `Alt+1` | 원본 PDF 목록으로 이동 |
| `Alt+2` | 주소 입력칸으로 이동 |
| `Alt+3` | 추천 목록으로 이동 |
| `Alt+4` | 출력 폴더 파일 목록으로 이동 |
| `Alt+5` | 주소 영역 키보드 편집 |
| `Enter` | 주소 검색 또는 현재 목록 항목 선택 |
| `Ctrl+Enter` | 어느 패널에서든 현재 선택으로 파일 복사 (영역 편집은 먼저 확정) |
| 마우스 뒤로 / 앞으로 (`XButton1` / `XButton2`, Windows) | 두 버튼 모두 `Ctrl+Enter`와 동일하게 파일 복사 |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 이전/다음 PDF 파일 |
| `Ctrl+R` | 영역 다시 읽기 |
| `F8` | 현재 영역을 OCR로 다시 읽기 |
| OCR 중 `Esc` | OCR 취소, 현재 입력 유지 |
| `PageUp` / `PageDown` | PDF 이전/다음 페이지 |
| `Ctrl+-` / `Ctrl++` | PDF 축소/확대 |
| `Ctrl+0` | PDF 폭 맞춤 |
| 영역 편집 중 `방향키` / `Shift+방향키` | 영역 이동 / 크기 조절 (`Ctrl`과 함께 미세 조절) |
| 영역 편집 중 `Enter` / `Esc` | 추출·확정 / 변경 취소 |
| 뷰어에서 편집 중이 아닐 때 `방향키` | PDF 화면 이동 |
| 주소 입력 중 `Shift+방향키` | 텍스트 선택 |
| `F5` | 목록 새로고침 |

Windows에서는 앱 내부에 마우스 포인터를 둔 상태로 뒤로/앞으로 버튼을 누르면 복사합니다.
Logitech MX Master 3S도 기본 뒤로/앞으로 입력을 사용하면 별도 매핑 프로그램이나 인터넷 연결이 필요하지 않습니다.
OCR 인식 중이거나 영역 편집 중이면 `Ctrl+Enter`와 동일하게 복사를 보류합니다.
복사 성공 후에는 ‘복사 후 다음 미처리 파일로 이동’ 옵션을 따릅니다.

## 개발 실행

Python 3.13을 사용합니다. 프로젝트 루트에서 가상환경을 만들고 의존성을 설치합니다.

```powershell
& "$env:LOCALAPPDATA\Python\pythoncore-3.13-64\python.exe" -m venv --without-scm-ignore-files .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe app.py
```

실행에는 `PyMuPDF`, exe 빌드에는 `PyInstaller`가 필요합니다.
가상환경을 활성화하지 않아도 위처럼 프로젝트 Python을 직접 실행할 수 있습니다.
활성화하려면 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

## 테스트

기존 로직과 PDF 영역 좌표·추출 및 GUI 동작을 검사합니다. GUI 테스트는 Windows 데스크톱에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest
```

`test_ocr.py`는 모델 무결성, OCR 취소·오류·이전 결과 방지 및 실제 PDF의 주소·PNU 결과를 검사합니다.
로컬 샘플이 없으면 실제 파일 검사만 생략합니다. 결과는 `build/ocr-actual-results.json`에 저장합니다.
검증 대상은 와룡동 2-122 측량성과도와 우이동 106-1 토지대장입니다.
OCR 엔진과 언어 모델의 출처·라이선스는 [assets/ocr/README.md](assets/ocr/README.md)를 참고하세요.

GUI 없이 소스 또는 빌드된 exe의 OCR 워커를 검증할 수도 있습니다. 영역 좌표는 페이지 대비 0~1 비율입니다.

```powershell
.\.venv\Scripts\python.exe app.py --ocr-check '검사할.pdf' --region 0.1 0.1 0.5 0.2 --page 1 --output 'build/ocr-check.json'
```

## 수동 테스트 자료

전달할 테스트 PDF는 프로젝트의 `test_files/` 폴더 바로 아래에 넣습니다.
앱에서 원본 PDF 폴더로 `test_files/`를 선택하면 됩니다. 하위 폴더의 PDF는 읽지 않습니다.
복사 결과를 확인할 출력 폴더는 원본 폴더와 별도로 선택합니다.

`test_files/` 내부 자료는 `.gitignore`로 Git 추적에서 제외하며, 폴더 유지를 위한 `.gitkeep`만 추적합니다.
자동 테스트 코드인 `test_app.py`는 계속 추적합니다.

## 빌드

PyInstaller로 onefile/windowed exe를 생성합니다.

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean '법정동PNU파일복사도구.spec'
```

빌드 결과는 기본적으로 `dist/법정동PNU파일복사도구_v0.7.3.exe`에 생성됩니다.
버전은 `version.py`에서 관리하며 창 제목과 exe 이름에 함께 반영됩니다.

### Mac에서 GitHub Actions로 Windows exe 빌드

`.github/workflows/build-windows.yml`은 GitHub의 Windows 2022 x64 환경에서
Python 3.13 x64로 테스트와 빌드를 실행합니다. Mac에 Windows를 설치할 필요가 없습니다.

1. 단축키 수정과 워크플로 파일을 커밋하고 GitHub의 `main` 브랜치에 push합니다.
2. 저장소의 **Actions → Build Windows EXE**에서 실행 결과를 엽니다.
3. 성공한 실행 화면 아래 **Artifacts → filemaker-windows-amd64**를 다운로드합니다.
4. ZIP을 풀고 `법정동PNU파일복사도구_v0.7.3.exe`를 오프라인 Windows amd64 PC로 옮깁니다.

`main`에 push할 때마다 자동 빌드합니다. 워크플로가 기본 브랜치에 등록된 후에는
**Actions → Build Windows EXE → Run workflow**로 수동 빌드할 수도 있습니다.
결과물 보관 기간은 30일이며, 별도 토큰이나 Secrets 설정은 필요하지 않습니다.
코드 자료와 OCR 모델도 exe에 포함되어 대상 PC에는 Python이나 인터넷 연결이 필요하지 않습니다.

자동 검사는 파일·주소 처리, 비동기 복사, PDF 영역 좌표·텍스트 추출,
OCR 모델 무결성 및 오류 처리와 Windows 목록 선택·새로고침 이벤트를 대상으로 합니다.
별도 PDF 프로세스의 동시 실행·재사용·취소·시간 초과, 캐시 상한과 이전 결과 방지도 검사합니다.
빌드된 exe에서도 합성한 텍스트/스캔 PDF를 읽어 렌더링·OCR 자식 프로세스를 확인한 뒤 업로드합니다.
실제 마우스 장치와 전체 GUI 작업 흐름은 대상 Windows PC에서 별도로 확인합니다.
