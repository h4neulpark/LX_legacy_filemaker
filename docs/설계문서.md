# 법정동 PNU PDF 정리 도구 설계 문서

작성일: 2026-06-23

## 1. 목적

이 프로그램은 PDF 문서를 사람이 확인한 뒤, 법정동 코드와 지번을 조합해 PNU 코드를 만들고, 선택한 원본 PDF를 규칙화된 파일명으로 출력 폴더에 복사하는 Tkinter 기반 데스크톱 도구이다.

핵심 목표는 다음과 같다.

- 원본 PDF를 프로그램 안에서 바로 확인한다.
- 법정동 코드 TXT에서 현재 존재하는 법정동만 사용한다.
- 주소 일부 검색으로 법정동 후보를 찾고, PNU와 최종 파일명을 자동 생성한다.
- 복사 완료 상태를 입력 폴더에 저장해 다음 실행 때 이어서 작업한다.
- 마우스 사용을 줄이기 위해 주요 업무 흐름에 단축키를 제공한다.
- Python이 설치되지 않은 환경에서도 실행할 수 있도록 PyInstaller standalone exe로 배포한다.

## 5. 화면 구성

메인 화면은 `ttk.PanedWindow` 기반 3영역 구조이다.

### 5.1 왼쪽: 원본 PDF 탐색기

역할:

- 원본 PDF 폴더 선택
- 선택한 폴더의 직속 PDF만 목록 표시
- PDF 선택 시 현재 원본 파일로 설정하고 PDF 뷰어에 로드
- 현재 세션 또는 저장 상태에서 처리 완료된 PDF는 `[완료]`로 표시
- 목록 아래에 전체 PDF 개수와 남은 PDF 개수를 표시

특징:

- 하위 폴더는 탐색하지 않는다.
- `.pdf`, `.PDF` 등 확장자 대소문자는 구분하지 않는다.
- 목록 표시 형식은 `[완료] 파일명.pdf` 또는 `[대기] 파일명.pdf`이다.

### 5.2 가운데: PDF 뷰어

역할:

- 선택한 PDF의 현재 페이지를 앱 내부에 렌더링
- 이전/다음 페이지 이동
- 확대/축소
- 폭 맞춤
- 외부 PDF 뷰어로 열기
- 스크롤바, 마우스, 키보드로 화면 이동

렌더링 방식:

1. `fitz.open()`으로 PDF를 연다.
2. 현재 페이지를 pixmap으로 렌더링한다.
3. pixmap을 PPM bytes로 변환한다.
4. Tkinter `PhotoImage`에 올려 canvas에 표시한다.

PDF가 손상되었거나 렌더링에 실패하면 뷰어 영역에 오류를 표시한다. 단, 원본 파일 복사 자체는 PDF 렌더링 성공 여부와 별개로 처리할 수 있다.

### 5.3 오른쪽: 출력/주소/복사 패널

역할:

- 법정동 코드 파일 로드 상태 확인
- 출력 폴더 선택
- 출력 폴더 파일 목록 표시
- 연도 선택
- 문서 종류 선택
- 주소 검색과 법정동 추천 목록 표시
- 선택된 법정동, PNU, 전체 주소, 최종 파일명 미리보기
- 최종 복사 실행

주소 검색은 자동 실행되지 않는다. 사용자가 주소를 입력한 뒤 `검색` 버튼을 누르거나 Enter를 눌렀을 때만 검색한다.

## 6. 법정동 데이터 로드

앱 시작 시 기본 법정동 코드 파일을 자동 로드한다.

검색 위치:

- 일반 실행: `app.py`가 있는 폴더의 `법정동코드 전체자료.txt`
- PyInstaller 실행: `_MEIPASS` 내부에 번들된 `법정동코드 전체자료.txt`

인코딩 시도 순서:

1. `utf-8-sig`
2. `cp949`
3. `euc-kr`

파싱 방식:

- 탭 구분 파일을 우선 처리한다.
- 탭이 없으면 공백 기반 테이블로 처리한다.
- 헤더에서 `법정동코드`, `법정동명`을 찾는다.
- 존재 여부 컬럼은 `존재여부`, `폐지여부`, `폐지 여부`, `존폐여부` 후보를 지원한다.
- 존재 여부 값이 정확히 `존재`인 행만 캐시에 보관한다.

검색 성능을 위해 각 법정동은 원본 이름과 공백 제거 이름을 함께 보관한다.

## 7. 주소 검색과 후보 선택

사용자는 주소 입력칸에 법정동명과 지번을 함께 입력한다.

예:

- `서울 강남구 역삼동 123-4`
- `경기 성남시 분당구 정자동 산12-3`

검색 흐름:

1. 사용자가 주소를 입력한다.
2. `검색 (Enter)` 버튼 또는 Enter 키로 검색한다.
3. 입력값에서 지번 부분을 제외한 검색어로 법정동 후보를 찾는다.
4. 후보 목록을 점수순으로 표시한다.
5. 첫 번째 후보를 자동 선택한다.
6. 선택된 후보를 기준으로 PNU, 전체 주소, 파일명 미리보기를 즉시 갱신한다.

검색 결과가 없으면 다음 상태가 된다.

- 선택된 법정동을 해제한다.
- 선택 정보에 `검색 결과가 없습니다.`를 표시한다.
- PNU, 전체 주소, 파일명 미리보기를 초기화한다.

사용자가 추천 목록에서 다른 후보를 클릭하거나 Enter를 누르면 해당 후보가 다시 선택된다.

## 8. 지번 파싱과 PNU 생성

지번 파싱 규칙:

- 일반 지번: `123`, `123-4`
- 산 지번: `산12`, `산12-3`
- 본번과 부번은 최대 4자리로 처리한다.

PNU 형식:

```text
법정동코드10자리 + 산여부1자리 + 본번4자리 + 부번4자리
```

산 여부:

| 유형 | 값 |
| --- | --- |
| 일반 지번 | `1` |
| 산 지번 | `2` |

예:

| 입력 지번 | PNU 지번 부분 |
| --- | --- |
| `123` | `101230000` |
| `123-4` | `101230004` |
| `산12-3` | `200120003` |

전체 주소는 사용자가 입력한 원문 전체가 아니라 다음 값으로 정규화한다.

```text
선택된 법정동 전체명 + 파싱된 지번 표시 문자열
```

지번을 파싱하지 못하면 복사를 차단하고 사용자에게 지번을 포함해 입력하라는 오류를 표시한다.

## 9. 파일명 생성과 복사

최종 파일명 형식:

```text
{연도}_{문서종류}_{PNU코드}_{공백을_언더바로_대체한_전체주소}.{원본확장자}
```

예:

```text
2026_실태조사서_1168010100101230004_서울특별시_강남구_역삼동_123-4.pdf
```

처리 규칙:

- 원본 확장자는 유지한다.
- 전체 주소의 공백은 `_`로 바꾼다.
- Windows 파일명 금지 문자 `\ / : * ? " < > |`는 `_`로 치환한다.
- 동일 파일명이 없으면 무번호 파일명으로 복사한다.
- 동일 무번호 파일명이 이미 있으면 경고창으로 확인을 받은 뒤 기존 무번호 파일을 `__1`로 변경하고 새 복사본을 `__2`로 만든다.
- 이미 `__1`, `__2` 같은 번호 파일만 있고 무번호 파일이 없으면 다음 빈 번호를 새 복사본에 붙인다.
- 무번호 파일과 번호 파일이 함께 있으면 기존 번호 파일을 뒤로 밀어 보존한 뒤, 무번호 파일을 `__1`, 새 복사본을 `__2`로 만든다.
- 실제 복사는 `shutil.copy2()`로 수행해 원본 메타데이터를 가능한 보존한다.

복사 성공 후 처리:

1. 현재 원본 PDF를 처리 완료 set에 추가한다.
2. 작업 상태 JSON을 저장한다.
3. 원본 PDF 목록을 새로고침하되 저장 상태로 덮어쓰지 않는다.
4. 현재 PDF 선택을 복원한다.
5. 출력 폴더 목록을 새로고침하고 새 파일을 선택 표시한다.

## 10. 작업 상태 저장

입력 폴더마다 다음 파일을 자동 생성한다.

```text
.filemaker_work_state.json
```

저장 위치는 사용자가 선택한 원본 PDF 폴더 바로 아래이다.

저장 내용:

```json
{
  "version": 1,
  "source_folder": "원본 PDF 폴더",
  "output_folder": "출력 폴더",
  "processed_files": ["완료된.pdf"],
  "last_selected_pdf": "마지막선택.pdf",
  "year": "2026",
  "doc_type": "실태조사서"
}
```

저장 시점:

- 원본 폴더 선택 또는 변경
- 출력 폴더 변경
- PDF 선택
- 복사 성공
- 연도 변경
- 문서 종류 변경

복원 방식:

- `processed_files`는 파일명 기준으로 현재 입력 폴더의 직속 PDF와 매칭한다.
- 내부적으로는 `Path.resolve()` 기준의 set으로 관리한다.
- 마지막 선택 PDF가 현재 입력 폴더에 있으면 자동 선택하고 PDF 뷰어에 로드한다.
- 저장된 출력 폴더가 존재하면 출력 목록도 자동 갱신한다.
- 상태 파일이 없거나 JSON이 손상되었으면 빈 상태로 시작한다.

| `Shift+Down` | PDF 화면 아래로 이동 |
| `Shift+Left` | PDF 화면 왼쪽으로 이동 |
| `Shift+Right` | PDF 화면 오른쪽으로 이동 |
| `F5` | 원본 목록과 출력 목록 새로고침 |

단축키 구현 메모:

- `Alt+1`은 현재 로드된 `self.source_file`을 원본 목록에서 찾아 선택, 활성화, 표시한다.
- 현재 PDF가 목록에 없거나 아직 선택된 PDF가 없을 때만 첫 번째 PDF를 선택한다.
- `PageUp`, `PageDown`, `Shift+방향키`는 목록이나 입력칸에 포커스가 있어도 PDF 뷰어 동작이 우선되도록 `"break"`를 반환한다.
- `Shift+방향키` 화면 이동은 canvas의 `xview_scroll()`, `yview_scroll()`을 사용하며 한 번에 3 units 이동한다.

## 12. PDF 조작

마우스 조작:

- 마우스 휠: PDF 확대/축소
- 가운데 버튼 드래그: PDF 화면 이동
- 스크롤바: PDF 화면 이동

버튼 조작:

- `이전 (PageUp)`: 이전 페이지
- `다음 (PageDown)`: 다음 페이지
- `축소 (Ctrl+-)`: 확대 배율 감소
- `확대 (Ctrl++)`: 확대 배율 증가
- `폭 맞춤 (Ctrl+0)`: 캔버스 너비 기준으로 페이지 맞춤
- `외부 열기`: OS 기본 PDF 프로그램으로 현재 PDF 열기

확대/축소를 직접 수행하면 `fit_to_width=False`로 전환된다.

- Tkinter
- PyMuPDF
- `법정동코드 전체자료.txt`

## 15. 현재 제약

- PDF 안의 텍스트 자동 추출이나 OCR은 포함하지 않는다.
- 사용자가 PDF를 보고 주소를 직접 입력하는 워크플로우를 전제로 한다.
- 원본 PDF 탐색은 선택한 폴더의 직속 PDF만 대상으로 한다.
- 작업 완료 상태는 입력 폴더별 JSON 파일에 저장하며, 별도 중앙 DB는 없다.
- 작업 상태 JSON은 숨김 속성을 설정하지 않고 파일명만 점으로 시작한다.
- GUI 렌더링과 단축키는 Windows/Tkinter 환경에서 수동 확인이 필요하다.
