# v0.7.0 측량성과도 읽기와 일괄 복사

`survey_ocr.py`는 토지소재와 면적표 지번 열을 독립된 페이지·상대 좌표로 읽는다.
토지소재에 텍스트가 있으면 직접 추출하고 없으면 300dpi OCR을 사용한다.
지번 열은 숨은 OCR 레이어의 색을 신뢰하지 않고 RGB로 렌더링한다.
450dpi를 기본으로 사용하며 영역은 최대 약 600만 화소로 제한한다.
픽셀의 채널 차이와 밝기로 검정/회색을 남기고 빨강을 제거한 후 기존 kor+eng 모델로 읽는다.
색이 불명확한 후보는 제외 상태로 제시한다. 사용자가 포함 여부와 산 표기를 수정할 수 있다.
OCR 줄별로 지번을 엄격히 검증하고 정규화·중복 제거한다. 면적이나 도면 전체를 읽지 않도록 ROI를 제한한다.

`PdfPipeline.prepare`의 동일한 재사용 프로세스에서 survey 작업을 실행한다.
파일 수정 시각/크기와 두 영역으로 캐시를 구분하며 현재 문서 세대·수정 번호가 맞을 때만 결과를 반영한다.
사용자가 주소 검색·추천 선택·직접 입력을 하면 현재 읽기를 취소한다.
다음 미처리 파일 1개의 화면과 두 영역을 미리 준비한다.
복사 후 캐시된 화면이 즉시 표시되는 경우도 입력 잠금 해제 뒤 자동 읽기를 이어간다.

`survey_ui.py`는 전용 도구, 두 영역 드래그, 후보의 포함/제외·수정·원문 표시를 담당한다.
측량성과도에서는 기존 단일 영역 도구와 단일 미리보기를 숨긴다.
법정동 코드는 현재 앱 자료에서 선택한 항목을 사용한다. 파일명의 코드로 대체하지 않는다.
모든 행의 PNU/파일명은 공통 법정동과 각각의 지번으로 생성한다.
복사 전에 사용자의 확인 체크를 요구하며 파일·주소·영역·목록이 바뀌면 확인을 해제한다.

## 재시도와 상태

`survey_batch.py`는 한 스레드에서 선택 항목을 순차 복사하며 Tk 객체를 읽지 않는다.
복사 작업은 원본 식별자, 선택 법정동, 연도, 출력 폴더와 지번으로 식별한다.
배치 시작 전에 원본 해시를 구하고 각 항목의 복사 예정 경로를 원본 폴더 상태 파일에 먼저 기록한다.
복사·내용 검증 뒤 성공을 다시 기록한다. 첫 복사가 끝나고 성공 기록 전에 종료돼도
다음 실행에서 예정 경로의 이름·위치·해시가 일치하면 성공으로 재사용할 수 있다.
일부 실패한 경우 원본 완료 표시와 다음 파일 이동은 보류한다.

기존 상태 형식(version 1)에 다음 선택 필드를 추가한다.

- `survey_regions`: 토지소재/지번 열의 페이지와 상대 좌표
- `survey_progress`: 작업 키별 예정/성공 경로·원본 내용 해시·항목 상태
- `survey_batches`: 미완료 배치의 원본 식별자, 선택 코드, 연도, 출력 폴더, 수정한 지번·포함 여부

재시작 시 현재 원본·연도·출력 폴더와 일치하는 최신 미완료 목록을 복원한다.
법정동 코드는 현재 자료에 존재하는 경우에만 복원하며 확인 체크는 해제한다.
전체 성공 시 해당 배치의 재시도 정보는 제거하고 원본 완료/마지막 선택을 저장한다.
완료 뒤 같은 원본을 다시 복사하면 일반 충돌 번호 규칙으로 새 복사본을 만든다.

일반 실태조사서의 상태 저장은 기존 v0.6.1처럼 최종 상태 1회이다.
측량성과도 배치는 중간 종료 복구를 위해 항목별 복사 전·후 체크포인트와 최종 상태를 저장한다.
전체 경로를 다시 탐색하거나 출력 목록을 매번 재생성하지 않는다.

## 검증

- 실제 사용자 예시는 로컬에서만 읽으며 GitHub에 올리지 않는다.
- 합성한 텍스트/스캔 PDF로 빨간 고유 지번 999-9와 면적 숫자가 제외되는지 검사한다.
- 부분 실패 재시도, 성공 기록 전 중단, 원본/출력 변경, 상태 쓰기 실패, 임시 파일 정리와 번호 복원을 검사한다.
- Windows Tk에서 모드 전환, 확인 체크, 세 복사본, 캐시된 다음 파일 읽기를 검사한다.
- Actions는 빌드한 exe의 실제 survey UI를 띄워 합성 PDF 인식과 세 복사본의 내용까지 검증한다.
  화면 캡처가 가능한 실행기에서는 `survey-ui-preview` 아티팩트를 제공한다.
